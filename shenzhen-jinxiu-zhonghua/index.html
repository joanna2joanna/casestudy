项目简介

锦绣中华·中国民俗文化村在深圳南山区深南大道，坐着华侨城商圈最核心的一块地。1989年11月22日开业，是中国内地第一座主题公园，比深圳世界之窗还早五年。园区分两块：一侧的锦绣中华微缩景区把82处中国名胜缩到一园之内，多数按1:15比例建造，配上五万多个陶艺小人，被叫作「小人国」；另一侧的中国民俗文化村1991年10月1日开园，按1:1盖起24个民族的村寨，口号是「二十四个村寨，五十六族风情」。2003年1月1日两园合并，一票通玩。三十多年里累计接待近7000万人次，1992年的客流峰值放到今天仍然是国内主题公园的前列。眼下的挑战不在客流，而在地段：身处深圳房价最高的一片区域，靠静态景观收门票的模式越来越撑不住，园区近年的动作是把「造景」改成「造境」——让游客走进戏里，2024年底与腾讯视频联手的「锦绣盛市·梦华录」主题区是这条线上最新的一步。

设计与建设：从造景到造境

1989年开园时的设计思路是「缩地成寸」：把中国最有名的景观按比例搬进一座园子，游客半天走完大江南北。这在当年是国内从未有过的产品形态，开业一年左右即收回投资。三十多年后，同一套逻辑遇上了麻烦——静态微缩景观看一次就够，复访率上不去，而园区脚下的土地价值早已翻了几十倍。园方的应对是把体验从「看」推到「进」：村寨里加互动演艺，街面上加 NPC，2024年底与腾讯视频联合推出占地2万平方米的「锦绣盛市·梦华录」主题区，把影视 IP 的十大组团场景搬进园区，走「场景 + 演艺 + NPC + 餐饮 + 文创」的组合。华侨城将这条路径概括为从「造景」到「造境」。

锦绣中华微缩景区

一园看遍中国。82处微缩景观多数按1:15比例建造，长城、故宫、布达拉宫、莫高窟等名景相距数百步，配上五万多个陶艺小人，构成「小人国」的观感。

中国民俗文化村

按1:1比例建成的24个民族村寨，覆盖21个民族的居住与生活场景。村寨不是布景板，常年有歌舞、手作与节庆活动在里面发生。

翠湖

园区中心约2万平方米的水面，是水上实景演出的舞台。近年推出的非遗秀在此上演，打铁花、火壶钢花与百米游船都在湖面上完成。

锦绣盛市 · 梦华录

2024年12月31日与腾讯视频联合推出的2万平方米主题区，含锦绣楼、勾阑瓦肆、樊楼、州桥夜市等十大组团场景，走「场景 + 演艺 + NPC + 餐饮 + 文创」的组合。

驻场演艺

《龙凤舞中华》上演二十余年、6000余场，2025年焕新；《大漠传奇》以百名马术演员与近百匹战马复原丝路沙漠战景；另有《东方霓裳》等剧目。

节庆与街区

2026年元旦推出「印象中国·京剧沉浸街区」与新春非遗灯会，把演出从固定剧场扩散到街区，是园区从静态观览转向沉浸式体验的一条支线。

投资与建设时序

1986年

筹资

中旅集团与华侨城共同筹集1亿港元（当时约合7000万元人民币），启动锦绣中华微缩景区建设。

1988年8月4日

运营公司成立

深圳锦绣中华发展有限公司成立，为香港中旅国际投资与深圳华侨城的合资公司。

1989年9月

部分建成试业

景区先期开放部分区域，同年11月22日正式开业，成为中国内地第一座主题公园。

1991年10月1日

中国民俗文化村开园

紧邻微缩景区，按1:1建起24个民族的村寨，投资约1.1亿元，开业约一年半收回投资。

1992年

客流峰值年

两景区当年接待量达到峰值，各来源口径为716万至730万人次，在全国主题公园中居首。此后随同类项目增多逐年回落。

2003年1月1日

两园合并

微缩景区与民俗文化村合并为一体化经营的景区，实行一票通玩。合并首日截至下午4时入园7000余人。

2019年11月

开园30周年

累计接待海内外游客近7000万人次，累计营业收入逾50亿元，利润总额超15亿元。

2024年12月31日

锦绣盛市·梦华录首发

与腾讯视频联合打造的2万平方米主题区开放，园区从静态景观转向沉浸式国风体验的标志性动作。

2025年11月

土地处置传闻与公司回应

市场出现锦绣中华到期土地将推进处置的传闻，华侨城A发布股票交易异常波动公告，称经营正常、无应披露未披露重大信息，但未明确肯定或否认传闻。

2026年

内容继续加密

元旦推出「印象中国·京剧沉浸街区」与新春非遗灯会，同期开启「2026华侨城团圆季」联动活动。

运营指标

客流：峰值在1992年，近年靠节假日的阶段性增长

1992年的716万至730万人次是这座园子的历史峰值，此后随国内主题公园供给增加逐年回落，1995年锦绣中华已降至122.34万人次。近年公开数据以节假日为主：2023年五一五天累计客流较2019年同期明显增长，夜场客流较2019年同期增长418%；2024年国庆首日日场游客较2023年同期增长约60%，前八个月接待境外游客同比增长1125%；2025年春节假期接待约13万人次，大年初一近3万人次；2026年五一首日客流突破1.5万人次。2023至2025年的全年客流，公开渠道未见单列数据。

母公司视角：华侨城主题公园板块承压

锦绣中华是华侨城主题公园品牌矩阵中的一员，与欢乐谷全国8座园区、世界之窗并列。母公司华侨城A的财报显示，2025年营业收入313.81亿元、同比下降42.32%，归母净利润亏损144.96亿元；旅游综合行业收入213.72亿元、同比下降21.71%，但占营收比重升至68.10%，全年文旅项目接待游客7970万人次。年报点名锦绣中华《龙凤舞中华》焕新上演。锦绣中华自身的营收从未在年报中单独披露，历年均并入「旅游综合行业」口径。对一座坐在深圳核心地段、开业三十七年的园区来说，土地价值与经营收益之间的落差，是它绕不开的结构性问题。

最新动态与展望

国风与国潮：从造景到造境

园区把转型方向概括为从「造景」到「造境」，从静态微缩景观转向沉浸式国风文化体验，被华侨城列为产品业态升级与「首发经济」的实践样本。2024年底的「锦绣盛市·梦华录」和2026年初的京剧沉浸街区，都是这条线上的动作。

2025年11月：土地传闻与股价异动

华侨城A在2025年11月11日年内首次两连板，市场流传两条消息：锦绣中华到期土地将推进处置以盘活土地资源，以及深圳欢乐谷可能整体搬迁至光明区。媒体报道明确称传闻「未获官方证实」；公司当日发布股票交易异常波动公告，称经营正常、无应披露未披露重大信息、控股股东正实施增持，但公告并未明确肯定或否认传闻。截至2026年9月，没有官方确认的关闭、转让或土地收回事实。

与腾讯视频的 IP 合作

「锦绣盛市·梦华录」是园区第一次把影视 IP 的完整场景体系搬进景区，占地2万平方米、含锦绣楼与州桥夜市等十大组团。这条路径能否带来复访，是判断园区转型成效的关键观察点。

母子公司的双重压力

母公司华侨城A 2025年营收同比下降42.32%、归母净利润亏损144.96亿元，文旅板块虽在营收中占比升至68.10%，但整体仍处收缩期。锦绣中华自身营收从未单独披露，其转型进度与集团的资本开支节奏绑定在一起。
