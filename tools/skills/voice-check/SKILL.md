# 去味红线速查

在 shuorenhua + humanizer-zh 改完之后跑一次。只看真实踩过的坑，不泛扫。14 条硬上限，其余一概不管。

## 使用方式

读完去味后的全文，逐条过。输出格式：

```
✅ 全部通过（14/14）
```
或
```
⚠️ 命中 N 条
  #1 「不是……而是……」→ 第3段「但我怕的并不是……而是……」
  #2 排比三连 → 第2段「没有树、没有村庄、没有任何过渡」
```

## 一、保真底线（先保护，再检查）

以下绝不误杀：

- 第一人称身体感受（「喘不过气」「怕惊动它」「只听见自己的呼吸」）
- 具体地名/数据（「百色凌云」「高美湿地」「两百潜」「Shallow water blackout」）
- 引号内的俗语/术语（「珍爱生命，远离洞潜」「浅水浸死人」）
- 有意的诗意重复（不是AI啰嗦，是节奏需要）

## 二、句式红线（量化）

| # | 红线 | 上限 |
|---|------|------|
| 1 | 「不是……而是……」 | 全文 0 |
| 2 | 排比三连（没有X、没有X、没有X / X、X、X） | 全文 0 |
| 3 | 「与其X不如Y」 | 全文 0 |
| 4 | 「忽然」「突然」「顷刻」「闪现」 | ≤ 2 个 |
| 5 | 「越……越……」句式 | ≤ 1 处 |
| 6 | 自问自答（「那么，……呢。」） | ≤ 2 处 |
| 7 | 破折号 | 每段 ≤ 2 个 |

## 三、口吻红线

| # | 红线 | 处理 |
|---|------|------|
| 8 | narrator 腔：替读者推导因果 | 删「就容易」「这说明」「归根结底」 |
| 9 | 镜像对仗：两个从句结构完全对称 | 打破一个结构 |
| 10 | 极值判断壳：「最忘不了的」「真正残酷的是」 | 后面必须紧跟具体事实，否则删框架 |
| 11 | 解释预告壳：「原因很简单」「答案很朴素」 | 删预告，直接写原因 |

## 四、段落红线

| # | 红线 | 处理 |
|---|------|------|
| 12 | 连续 3 段「观点+解释+段尾总结」 | 改 1 段的信息进入方式 |
| 13 | 相邻句语义重复 | 同一段落内两句说同一件事 → 删一句 |
| 14 | 段尾抽象拔高 | 停在事实/场景/引语上，不概括 |

## 五、扫描顺序

1. 先扫句式（#1-7）——最快，grep 就行
2. 再扫口吻（#8-11）——通读时标
3. 最后扫段落（#12-14）——合并段落后才触发
4. 回头看保真底线，确认没误杀
